Get help with CF Mail

CF Mail supports two connection models: standard email accounts over IMAP/SMTP and self-hosted CloudMail Server accounts. Before requesting help, identify which account type is affected and, if possible, export a redacted diagnostic package from CF Mail.

In-app troubleshooting

  • Open Settings → Privacy & Security → Diagnostics & Logs to review or export local diagnostics.
  • Use the account's server/connection test where available.
  • For standard accounts, verify that IMAP/SMTP or provider-specific app-password/OAuth access is enabled.
  • For CloudMail, verify the configured CloudMail Server URL and account status.

Privacy when sharing diagnostics

CF Mail does not upload diagnostics automatically. The app is designed to redact authorization information, email addresses, subjects, message bodies, and attachment contents before user-initiated export. Review the exported package before sending it to anyone.

Contact

Email CF Mail Support at support@readori.com or visit cfmail.readori.com. If your issue is specific to a third-party email provider or a CloudMail Server operated by another organization, that provider/server operator may also need to assist.

获取 CF Mail 帮助

CF Mail 支持两类连接：标准 IMAP/SMTP 邮箱，以及自托管 CloudMail Server。请求帮助前，请先确认问题属于哪一种账户类型；如果可以，建议从 CF Mail 导出脱敏诊断包。

App 内排查

  • 进入设置 → 隐私与安全 → 诊断与日志查看或导出本地诊断。
  • 在支持的账户页面运行服务器/连接测试。
  • 标准邮箱请确认服务商已开启 IMAP/SMTP，或已按服务商要求配置 App Password / OAuth。
  • CloudMail 请确认 CloudMail Server 地址与账户状态正确。

分享诊断时的隐私

CF Mail 不会自动上传诊断信息。App 设计为在用户主动导出前，对授权信息、邮箱地址、主题、邮件正文与附件内容进行脱敏或排除。将诊断包发送给任何人之前，建议你先自行检查。

联系支持

请发送邮件至 support@readori.com 联系 CF Mail 技术支持，或访问 cfmail.readori.com。如果问题属于第三方邮箱服务商，或由其他组织运营的 CloudMail Server，也可能需要联系相应服务商/服务器运营者。
